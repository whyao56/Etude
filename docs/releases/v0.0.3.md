# Etude 0.0.3

> **这一版把 0.0.2 里最要命的一个 bug 修了（大模型语音取错了音色，整包静音），
> 并把「配图」改成两条路并行、把评分键搬回卡片正下方、补上了撤销和 Anki 式的进度调控。**
>
> 依然是那个把一句话练到「脱口而出」的本地工具 —— 给它一个词，它生成一组
> **不同上下文**的例句，把每一条铺成五种练法：阅读、听力、口语、打字、造句。
>
> *Etude*（/eɪˈtjuːd/）是音乐里的「练习曲」：专为练技巧而写，
> 不讲故事、不为演出，纯粹为了让手指形成本能。学语言是同一件事。

## 先说修好的那件事：例句读不出来

这是 0.0.2 里最该被早点发现的一个 bug，因为**它坏得毫无声息**。

配置里有两个**互不通用**的音色字段：

| 字段 | 装的是什么 | 例子 |
|---|---|---|
| `tts.voice` | Edge TTS 的音色名 | `en-US-AriaNeural` |
| `tts.openai.voice` | 大模型端点的音色名 | `alloy` |

但合成、补语音、试听三条路径**一律只读 `tts.voice`**。所以一旦你把语音切到
「大模型语音」，程序就会把 `en-US-AriaNeural` 发给 `/audio/speech`：

- OpenAI 官方 → `400 Invalid voice`
- 豆包 / 硅基流动 → 同样报参数错

**结果是每一条语音都失败，而失败只写进日志** —— 界面上是一次静默的「整包没声音」。
更糟的是设置页看着一切正常，因为当时自检只 `import edge_tts` 一下就算过了。

现在的改法：

- 音色的取法收敛到**唯一一处**，按引擎取对应的那一套，绝不互相退回。
- **自检改成真的出声**：静态层报出实际会用的音色；加 `--deep` 时真的合成一句短文。
  「音色取错」「密钥不对」「网络不通」这三类毛病当场暴露，
  而不是等你发现整包静音。
- 界面上试听按钮和「重新生成语音」走的是同一条路径。

## 这一版新在哪

### 1. 配图：检索和画图**同时**开跑

以前是二选一。现在多了一个来源 —— **「检索 + 画图并行」**，而且它就是默认值。

| 来源 | 怎么工作 | 花钱吗 |
|---|---|---|
| **检索 + 画图并行**（默认） | 两条路**同时**开跑，谁先给出合格的图就用谁 | 画图那条看你选的模型 |
| **只用开放图库检索** | Openverse 为主，Wikimedia Commons 兜底 | 免费、不需要密钥，需要联网 |
| **只用文生图模型** | 任意 OpenAI 兼容的 `/images/generations` | 看你选的模型 |
| **不要图** | 只用文字描述场景 | — |

**为什么是「先到先得」而不是「两个都等再择优」**：检索 1–3 秒、画图 8–25 秒，
差一个数量级。等两个都回来，等于把画图的慢**加**在检索身上 —— 那就不是并行了。

而先到先得有个可解释的必然结果：**绝大多数时候检索赢**（你拿到的是真照片），
只有检索限流 / 搜不到 / 超时时画图才接上场。这恰好就是想要的优先级，
而且是「顺带实现的」，不需要额外编一套打分权重去比较「真照片」和「画出来的图」
—— 那件事没有客观答案，硬编只会让结果变得不可解释。

顺手还改了生成质量：

- **文生图提示词重写**成四段（画面 / 怎么拍 / 硬性要求 / 反面清单），
  明确写「35mm、现场光、中景」。模型对这类摄影语言的响应远好于
  「photorealistic」一个形容词。不靠 `negative_prompt` 字段 —— 各家支持不一致。
- **检索词更准**：砍掉破折号之后那半截（那是「说了什么」，不是画面）、
  滤掉心理/言说动词（`worry` / `say` / `wonder` 在真实照片的标题里基本不出现）。
- **按标题命中数排序**。0.0.2 只看横图和分辨率，于是排序第一的经常是一张
  **高清但毫不相干**的图。现在「标题里有几个词对得上」参与排序 ——
  这是图库免费给的相关性信号。

### 2. 评分键回到卡片正下方，待用状态不再像禁用

评分键从侧边栏搬回了卡片正下方，横向四列。**评分键必须跟它要评的那张卡在一起**
—— 放在侧边栏时，眼睛要在页面两个角之间来回跑，而这是每次翻面都要做一遍的动作。

同时修了显示上的两个毛病：

- **「待用」被画成了「坏掉」。** 翻面之前后三档是不可评的，原来用**虚线边框 + 灰字**
  表示，但你看到的是一排发灰的按钮，和「禁用」没有区别。
  现在四档**长得完全一样**，区别只在右上角多一个「先看答案」的小标签。
- **「下次间隔」被提示语顶掉了。** 原来那句「先核对答案」占着本该显示
  「→ 3 天」的位置，于是翻面前根本看不出各档差多少 —— 而这恰好是
  选评分时唯一需要的信息。现在两个都显示，待用时只把间隔压暗一档。

### 3. 上一张 / 下一张 / 撤销

卡片下面多了一排导航键：

- **上一张** —— 只回看，**不改任何数据**。想看一眼前一句再回来，
  不会发现自己的进度变了。
- **下一张** —— 跳过，**不计入「本次已练」**。逼人评分只会得到假数据，
  污染间隔重复的输入。
- **撤销上一评** —— 把这张卡退回队列。

关于撤销，有两个不显眼但很要紧的决定：

- **连 `reviews` 那一行一起删掉。** 那张表是「今天已经练了多少」的依据，
  程序靠它决定还放多少新卡。撤了评分却留着记录，你会莫名其妙地发现
  新卡配额被吃掉了。
- **靠评分前存的快照回退，不靠公式反推。** 反推会因为浮点累积误差导致
  「撤销之后进度变了」。老记录（0.0.2 之前）没有快照时**直接拒绝执行**，
  而不是把卡清零 —— 清零等于凭空毁掉你的复习进度。

### 4. 手动调进度（Anki 式的灵活度）

你要的新手友好和老手调控，做成了**两档密度**：

- **简易**（默认）：只给必需的东西，不摆 SRS 数字，但明确说清去哪开。
- **进阶**：摊开间隔 / 难度 / 到期时间 / 卡片 id，侧边栏多显示已暂停的数量。

<img src="https://github.com/whyao56/Etude/blob/main/docs/images/15-cards-browser.png?raw=true" alt="卡片浏览页" width="700">

能力上：

- **逐张改**：间隔（连带把到期时间一起算出来，避免「间隔 30 天但明天到期」
  这种自相矛盾的卡）、难度（夹在 1.3~3.5，超出去会让间隔指数爆炸或永远推不动）、
  **打回新卡**（同时把间隔/次数/遗忘次数/上次评分归零）。
- **暂停**（Anki 里叫 suspend）。「今天不想看这一批」是真实需求：
  暂停的卡不进队列，也不计入「今天到期」的数字。
- **批量**：勾一批之后一起暂停 / 恢复 / 推后 1 天 / 推后 7 天 / 当作没学过。
  推后是从**各自当前的到期时间**往后推，不是统一设成「今天 + N 天」——
  后者会把一张压了三周的卡和一张今天到期的卡抹平成同一天。
- **卡片页能筛能搜能翻页**：训练包 / 通道 / 状态（新卡 / 学习中 / 已到期 / 已暂停）。
  没有这一层，「老手调控」就只是嘴上说说。
- **改例句**：原文、场景（中英）、语域、中文说法的增删改，
  外加「重新生成语音」「重新生成配图」「手动贴图片地址」三条单独的入口。
- **加例句时五个通道的卡片一起铺好**。只插例句不铺卡的话，你会得到一条
  「看得见但练不到」的例句：它出现在详情页里，点「练阅读」却什么都不发生。
- **删例句会连它的卡片一起删。** `cards.example_id` 允许是 0（整包级的卡），
  没法用外键约束，所以这段级联是手写的 —— 漏掉就会留下五张指向不存在例句的卡，
  练习时直接空屏。

### 5. 三套配色，跟着光线换

0.0.2 只有一浅一深两套，深色是 `#0b0d12` + `#e8ecf5`，对比度接近 16:1
（暗色界面的惯例是 9~11:1），而且所有颜色都偏蓝。现在：

| 暖白 · 护眼（默认） | 冷白 · 清晰 | 深色 · 夜间 |
|---|---|---|
| <img src="https://github.com/whyao56/Etude/blob/main/docs/images/18-theme-warm.png?raw=true" alt="暖白配色"> | <img src="https://github.com/whyao56/Etude/blob/main/docs/images/19-theme-light.png?raw=true" alt="冷白配色"> | <img src="https://github.com/whyao56/Etude/blob/main/docs/images/20-theme-dark.png?raw=true" alt="深色配色"> |

- **暖白 · 护眼**（默认）：米黄底 `#ebe6dc` + 暖灰字，长时间看不累。
- **冷白 · 清晰**：纯白底，白天光线足时对比更利落。
- **深色 · 夜间**：暖调深灰 `#191a1c`（不是纯黑），夜里不刺眼。
- **跟随系统** —— 它**不是第四套配色**，只是把「用哪套」的决定权交给系统。
  所以 `data-theme` 干脆不设，让 CSS 的媒体查询生效。这个区分让
  「白天想暖白、晚上跟着系统变深色」这种需求表达得出来。

字号还有三档（小 / 标准 / 大），字号和行距一起变。护眼这件事里，
**把字放大一点往往比把背景调暗更管用**。

### 6. 朗读兜底

Edge 和大模型都拿不到音频时，退到浏览器的语音合成。
语言标签（`en-US` / `ja-JP`）从语言目录里取 —— 缺了它，练英语会听见中文腔。

**打包版检查**：`scripts/e2e_check.py` **20/20**，显式把配图来源设成
「只用文生图模型」—— 不指定的话它会去联网检索，一个端到端检查就变成了
「外网可用性检查」。

**发版脚本补了一道闸**：打包前核对产物里的前端版本常量和要发的版号是否一致。
这道闸是踩出来的 —— `dist/` 下留着上次的构建目录时，脚本会老老实实挑它，
于是 0.0.3 的 zip 里装的可能是 0.0.2 的前端。**打包、算校验和、上传全部成功，
只有内容是错的**，而这类「标签对、内容错」的发版比打包失败糟得多。

**顺手修掉的两处界面 bug**（都是这次改动暴露出来的）：

- 卡片编辑抽屉改「界面密度」时**画面纹丝不动** —— 抽屉挂在 `<body>` 上，
  不在 `#app` 里，重画 `#app` 不会带上它。而这个开关恰好就在抽屉里，

- 关掉编辑抽屉会**掉回训练包列表**。`renderLessons()` 永远画列表，

  眼前从「这个包的 8 条例句」变成「新建训练包」的表单。

## 已知问题

- **语速 / 音量设置在「大模型语音」下仍然静默失效** —— 这一版只修通了音色。
- 「测试连接」遇到「豆包填了模型名而不是接入点 ID」时只报 404，不点明。
- 训练包详情仍未进地址栏（`#lessons/<id>`），刷新会回到列表。
- 只在 Windows 上打包和验证过，没有 macOS / Linux 的桌面包。
- **没有验证过真人长期使用效果。** 代码逻辑对着理论写了，但「照着练三个月会怎样」
  没有任何数据支持，也不应该被声称。
