# Etude 0.1.1

**0.1.0 是「重做了一遍」，0.1.1 是把重做完的东西真正做熟。**

上一版交出去之后收到的反馈是「仍然不满意，很多细节完全没做好」。这一版几乎每一条
改动都能对回某个具体的界面毛病：一句话被拼成了三句、同一个提示说了两遍、
按钮明明在上面却不该出现、点了没反应。功能上多了两样：一个进度页，和训练包的导入导出。

如果你只想让它跑起来：解压、双击 `Etude.exe`、进「训练」。老数据不用搬。

## 新的：进度页

第六个页面，一屏回答「我练得怎么样」：

- **今天练了几张**，以及「另有 N 次跟读」。
- **连续天数**：今天还没练不算断（锚点取今天或昨天），同时告诉你最长连过多少天。
- **最近两周的柱子**：高柱是复习过的卡，细条是跟读次数，今天那根有高亮。
  空着的那天不画柱、也不说教 —— 文案是「接着练就是」。
- **五个通道各一条**：浅色是总量、深色是练过的。「打字一张没碰」这种事实，
  以前要翻卡片浏览器才看得出来。
- **该回头看的**：按卡壳次数排前几张，点「练这张」直接进训练台。
- **跟读**：平均分、最高分、最近八次的小柱，以及「最近比最早高了几分」。

刻意没做的东西：排行榜、连续天数打卡特效、「预计还有 X 天学会」。
这三样都会让人为了数字练，而不是为了能开口练。

## 新的：导入 / 导出

训练包详情多了「导出 JSON」，训练包页多了「导入 JSON」。

导出的文件里只有文字：目标词、英英释义、音标、八条例句、场景、几种中文说法、换词表。
**不含语音和配图** —— 那些是二进制，塞进 JSON 会让一个几十 KB 的文件变成几十 MB。
导入回来的包会明确显示「缺语音」，详情页那个「补齐 3 条语音」的按钮就是给它准备的。

格式是稳定契约：`{"format": "etude-lesson", "format_version": 1}`。

## 新的：关于与快捷键

侧栏底部那行版本号现在是按钮。点开是：界面版本、后端版本、运行形态（源码 / exe）、
进程号、端口、数据目录，四个「打开目录」按钮（数据 / 日志 / 录音 / 备份），
以及「复制诊断信息」——出问题时报给别人的那一小段。

旁边的 `?` 是快捷键表。这九个键以前只写在侧栏角落的小字里。

## 新的：备份与恢复

- 设置 → 数据里能看见备份列表，可以恢复任意一份。
  **恢复前会先把现在的库自动备份一次**（`before-restore-*.sqlite3`），恢复也能后悔。
- **启动时自己检查**：距上一份备份超过 7 天就再做一份，只留最近 6 份。
  理由很直白：用户不会主动备份，而复习记录丢了是「练了三个月的东西没了」。

## 修掉的（都是界面上的真毛病）

| 毛病 | 之前 | 现在 |
|---|---|---|
| 评分键下面那行提示 | 四档解释被拼成一整句：「完全不记得，明天再说想了一会儿，或者念得磕巴正常想起来了…」 | 默认一句「怎么打分」，鼠标放到某一档上才换成那一档的解释 |
| 听力卡 | 同一件事说两遍（舞台一句、通道提示又一句） | 舞台只管「怎么练」，通道说明挪到侧栏 |
| 听力卡 | 进卡后要自己点播放 | 进卡自动放一遍，`R` 重放 |
| 打字卡的「对比」 | 通栏蓝色大按钮，没输入也能点 | 输入框右边的小按钮，没输入时禁用，回车也能提交 |
| 训练包详情 | 没开配图时，每条例句还占一块 200×140 的「没有图」虚线框 | 关掉配图就整块不画，文字铺满 |
| 训练包详情 | 语音已齐，「补齐缺的语音」还挂着，点了什么都不发生 | 只在真缺时出现，文案带条数 |
| 卡片页批量条 | 没勾选时五个按钮也都在，占着一整条 | 没勾选时只显示「勾几张卡，这里才会出现操作」 |
| 设置页 | 八张等高卡片一路到底，找一项要滚很久 | 顶部锚点条 + 滚动点亮当前节；温度和超时收进「高级」 |
| 关于抽屉 | 「关闭」点了报 `TypeError: close is not a function`，关不掉 | 已修（两个抽屉都是） |
| 快捷键表 | 「空格 / Enter」被拆成三个键帽 | 一组两个键帽 |
| 提示条 | 连点几次会堆满右下角，还盖住评分键 | 最多三条 |

## 升级注意

- 老数据直接能用。这一版**没有**改表结构，所以升级不需要迁移。
- 备份目录（`backups/`）里从这一版开始会自己多出 `etude-*.sqlite3`，
  每份大约等于你数据库的大小，最多 6 份。
- 想做「练了三周」的演示数据：`python scripts/seed_demo.py`
  （会往当前数据目录里写东西，别对着自己真正的库跑）。
