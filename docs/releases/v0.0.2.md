# Etude 0.0.2

> **这一版把「场景」做成了图，并加了「以目标为导向的学习计划」。**
>
> 依然是那个把一句话练到「脱口而出」的本地工具 —— 给它一个词，它生成一组
> **不同上下文**的例句，把每一条铺成五种练法：阅读、听力、口语、打字、造句。
>
> *Etude*（/eɪˈtjuːd/）是音乐里的「练习曲」：专为练技巧而写，
> 不讲故事、不为演出，纯粹为了让手指形成本能。学语言是同一件事。

## 这一版新在哪

### 1. 「场景」现在可以是一张图

「卡片正面给场景，不给中文翻译」是这套方法的关键 —— 给翻译就变成中译英了。
但**只有一行中文描述的场景，还是太容易退化成「中译英」**。

现在场景这一侧可以带一张图：

| 来源 | 怎么工作 | 花钱吗 |
|---|---|---|
| **开放图库检索**（默认） | 按场景去 Openverse 搜图，搜不到换 Wikimedia Commons | 免费、不需要密钥，需要联网 |
| **文生图模型** | 调任意 OpenAI 兼容的 `/images/generations` | 看你选的模型（预置智谱 CogView-3-Flash 有免费档） |
| **不要图** | 只用文字描述场景 | — |

**默认就是开着的。** 因为「场景」是这套方法里最关键的一环，
不该让你先去设置里打开一个开关才能看到它。

配图**只出现在「场景」这一侧**。听力卡上永远没有图 —— 那是方法本身的要求，
不是还没做。

### 2. 以目标为导向：先说清你要学成什么样

以前只能一个词一个词地建训练包。问题是**光是输入内容本身就占掉大量时间**，
而且很容易在东一个西一个地攒素材，没有一个整体。

新的「目标」页回答另一个问题：**我到底要学到什么程度。**

- 选语言（目录里列了 10 种，目前只有英语可用，其余会直说还没做）
- 选你拿它干什么：
  - **真正学会这门语言** —— 目标是听说读写认五条腿都站起来，能在真实情境里
    听懂、说出、读懂、写出。大纲要覆盖高频功能词、固定说法和句型。
  - **应付一场考试** —— 中考 / 高考 / 四级 / 六级 / 雅思 / 学术 / 托福 / 考研 / 商务。
  - **我自己描述** —— 比如「明年去澳洲打工度假，要能和房东、同事日常对话」。
- 选要储备多少个（1 / 10 / 20 / 50 / 自定义）

**然后不是直接开工，而是先出一份大纲：**

每条带着类型（词 / 固定说法 / 句型）、使用领域、CEFR band，
以及**为什么值得学这一条**。你勾掉不要的，再点开始。

> **为什么不做成「选个难度等级」？**
> 因为「过六级」和「真的会用」是两件事 —— 填「六级」是你需要过考试，
> 不等于你要学会这门语言。所以在程序里这是**两条不同的提示词路径**：
> 考试那条收到的约束里写死了一句
> 「一份『重要单词表』是一份失败的大纲」。
> 考试预设里的 CEFR band 只当范围参考，不当学习内容。

### 3. 数据攒多了可以搬到别的盘

音频每条约几十 KB，场景图每张几十到几百 KB。攒起来是会占地方的。

「设置 → 数据」里填一个目录就能把**整个数据目录**搬过去。规矩是：

- **复制成功才写指针** —— 中途失败等于什么都没发生，你还在原地
- **旧数据永远不自动删**，界面上会告诉你「确认新的能用之后再自己删」
- 记录「数据在哪」的指针文件**永远留在平台默认位置**
  （它是钥匙，跟着箱子一起搬就走不回来了）
- 搬完**要重启**才生效，界面会直接说，不会假装已经好了
- **环境变量锁住时，按钮会告诉你「按了也不会生效」** ——
  而不是让你按半天没反应

### 4. 界面重做

- 交互键全部移到**左侧边栏**，带**收缩按钮**（状态记在本地）
- 四个视图：训练 / 训练包 / 目标 / 设置
- 四个评分键常驻侧边栏，**没翻面之前也能点**：点后三档会先帮你翻面，
  并提醒你是在核对答案

### 5. 修掉了一个「升级后打不开」的 bug

**如果你是 0.0.1 的用户，一定要升这一版。**

0.0.1 的程序在启动时会先建表、再迁移。老库里 `lessons` 表已存在但没有
`plan_id` 字段，那句「建表」是空操作，紧接着建索引就报
`no such column: plan_id` —— **每次启动都崩**。

这个 bug 在开发机上永远不出现（那里永远是全新的库），
只有在**从 0.0.1 升级上来**的机器上才炸。

除了这个，还修了「评分按钮按不动」（翻面前后三档被灰掉但仍显示手形光标，
鼠标点了没反应、键盘却能用）和一个把 `I'd rather stay home` 判成短语的问题。

## 升级：数据会自动迁移

直接把新版的文件夹解压出来用就行（数据不在程序目录里）。

第一次启动时程序会自己把数据库补上新字段。**复习进度不会丢** ——
这一点有测试盯着：`test_upgrade.py` 里造了一个带非默认进度的 0.0.1 老库，
验证迁移之后 interval / ease / reps / lapses 原封不动。
只验证「能启动」是不够的，迁移把进度清零同样是数据事故。

## 隐私

- **API Key 只写在本机的 `config.json` 里**，不上传、不进仓库、也不会回传到界面。
- 服务只监听 `127.0.0.1`，同一局域网里的其他人访问不到。
- 所有训练数据、音频、场景图、复习记录都在你自己电脑上。
- 场景配图选了**开放图库检索**时会联网查询图片；选了文生图则把场景描述发给
  你自己配置的那个服务。**选「不要图」就完全不联网。**

## 安装

### 方式一：下载 exe（不用装 Python）

1. 下载并**解压整个文件夹**
2. 双击 `Etude.exe`
3. 先去「设置」填大模型（选厂商 + 粘 API Key + 点「测试连接」）
4. 到「训练包」页输入 `appreciate`，回车
   —— 或者到「目标」页，说清你要学到什么程度，让它排一份大纲

> 没有系统自带的 WebView2 时会自动改用浏览器打开界面，功能一样。

### 方式二：从源码跑

```bash
git clone https://github.com/whyao56/Etude.git
cd Etude/backend
python -m venv .venv && .venv/Scripts/activate
pip install -r requirements.txt
python run_etude.py
```

### 起不来怎么办

**第一站永远是自检**，它会直接告诉你缺什么：

```
Etude.exe --check
```

结果同时写在数据目录的 `logs/selfcheck.txt` 里。

## 已知限制（请务必读一下）

这一版能用，但请接受这三条：

1. **只在一台 Windows 机器上验证过。** 没测过：中文用户名下的路径、
   没有写权限的目录、杀毒软件拦截、公司代理环境、显示器缩放不是 100%。
2. **例句质量取决于你配的模型。** 程序不做质量校验。
   弱模型会偷懒给逐字翻译的「场景」，那样整套方法就退化成中译英了。
   **建议用指令遵循较强的模型。**
3. **真人长期使用效果未经验证。** 代码逻辑是照着理论写的，
   但「照着练三个月会怎样」没有任何数据支持，也不应该被声称。

其他：

- 只支持**英语**作为目标语言（语言目录里能看见其他 9 种，但会明确说还没做）。
- 发音打分**没做** —— 评分是你自己打的（打字卡除外，那是逐字面比对）。
- 场景配图的检索质量取决于开放图库；检索不到时留空，不会塞一张不相干的图。
- 进训练包详情的地址栏仍然是 `#lessons`，**刷新会回到列表**（功能没坏）。
- 语速设置在「大模型 TTS」下**静默失效**（Edge TTS 下正常）。
- 没有 macOS / Linux 包，没有多设备同步。

完整的「没做什么、没验证什么」清单在
[docs/STATUS.md](https://github.com/whyao56/Etude/blob/main/docs/STATUS.md) ——
那份文档存在的意义是：如果三个月后发现效果不好，
应该能从中看出**是哪个假设错了**，而不是笼统地觉得「这个方法不行」。

## 这一版改了什么（技术细节）

<details>
<summary>展开</summary>

**测试**：187 个用例（0.0.1 是 113 个）。新增 `test_images.py`(24) /
`test_plans.py`(21) / `test_data_location.py`(15) / `test_upgrade.py`(10)。
测试套件**不再依赖外网**（默认配图来源是联网检索，测试里全部桩掉）。

**界面检查**：`scripts/ui_smoke.js` 扩到 54 项，四个评分档改成**真实鼠标事件**
逐个点（`Input.dispatchMouseEvent` + `elementFromPoint`）。
0.0.1 漏掉「评分键按不动」这个 bug，正是因为当时用 `evaluate("grade(2)")` ——
那种方式绕过了 DOM 事件层。

**打包版检查**：`scripts/e2e_check.py` 20/20，并显式指定配图来源 ——
不指定的话它会去联网检索，一个端到端检查就变成了「外网可用性检查」。

**配图的文件格式判断**：扩展名只从**文件头**嗅探，不信 URL 后缀也不信
`Content-Type`。图床出错时爱返回「200 + 一页 HTML」，按后缀存下来就是一张
永远加载不出来的假图，而「文件非空」这种断言会一路放行。
