# Etude 0.0.1

> **首个版本。** 一个把一句话练到「脱口而出」的本地工具 ——
> 给它一个单词、短语或句子，它生成一组**不同上下文**的例句，
> 并把每一条铺成五种练法：阅读、听力、口语、打字、造句。
>
> *Etude*（/eɪˈtjuːd/）是音乐里的「练习曲」：专为练技巧而写，
> 不讲故事、不为演出，纯粹为了让手指形成本能。学语言是同一件事。

## 它和已有的「AI 生成语言卡片」工具有什么不一样

GitHub 上做这件事的项目已经不少（mnemorai、han-flash、anki_ai 等），
绝大多数是「**单词 → 卡片生成器**」。Etude 不是一个造卡器，而是一套**训练循环**，
而且有几条和直觉相反的规矩：

| 常见做法 | Etude 的做法 | 为什么 |
|---|---|---|
| 一个词一张卡 | **一条例句五张卡**（听/说/读/写/造句） | 看得懂 ≠ 听得出 ≠ 说得出。合成一张卡等于假设它们能互相迁移。 |
| 卡片正面给中文翻译 | 正面给**场景**：「什么情况下会说这句话」 | 给逐字翻译的话，练习就变成了中译英 —— 你在做翻译，不是在建立表达。 |
| 同一个中文解释反复出现 | 同一句话存 2~3 种**彼此不同**的中文说法，每次随机给一种 | 让大脑没法把英文锁死到某个固定中文上。 |
| 依赖 Anki + AnkiConnect | **自带训练器和间隔重复**，双击就能练 | 少一层依赖就少一处「配好了但没反应」。 |
| 例句要你手动喂 | 给一个词，**自动生成 8 条不同上下文的句子** | 「用大量不同例子重塑连接」里，凑例子是最费时间的一步。 |

这套规矩来自《学习观 07》。**六条主张逐条映射到哪一行代码**写在
[docs/THEORY.md](https://github.com/whyao56/Etude/blob/main/docs/THEORY.md) 里 ——
包括**哪些功能是刻意不做的**（比如听力卡上不放图片、不给语法讲解）。

## 这一版能做什么

**五种通道，各自独立调度**

| 通道 | 正面给什么 | 你要做什么 |
|---|---|---|
| 阅读 | 英文句子 | 在脑子里出现场景。**不读出声，不想中文** |
| 听力 | 只有声音 | 直接进入场景，**中间不经过图片和中文** |
| 口语 | 场景描述 | **真的出声说出来** |
| 打字 | 场景描述 | 打出英文 → 逐词比对（绿=对、红=漏/错、黄=多打） |
| 造句 | 原句 + 换词提示 | 换掉主/谓/宾，造一个新句子 |

**大模型接入** —— 7 家预置 + 任意 OpenAI 兼容端点

DeepSeek `deepseek-chat` · 通义千问 `qwen-plus` · 智谱 `glm-4-flash` ·
Kimi `moonshot-v1-32k` · 豆包（火山方舟）· OpenAI `gpt-4o-mini` ·
本地 Ollama `qwen2.5:7b` · 或你自己的 base_url

**语音合成** —— 两条路都行

Edge TTS（免密钥，7 个英文音色：美/英/澳）或任意 OpenAI 兼容 `/audio/speech`。
音频按内容寻址存盘，同一句话重复生成不会存两份。

**间隔重复** —— 简化版 SM-2

评「没想起来」会让这张卡 **10 分钟后再出现一次**，而不是推到明天 ——
当次会话里就该再遇到它。每天新卡配额可调（默认 5 张）。

**断网可练**

已经生成好的包里，例句、语音、复习进度都在本机。只有「生成新训练包」要联网。

## 隐私

- **API Key 只写在本机的 `%LOCALAPPDATA%\Etude\config.json` 里**，
  不上传、不进仓库、也不会回传到界面。
- 服务只监听 `127.0.0.1`，同一局域网里的其他人访问不到。
- 所有训练数据、音频、复习记录都在你自己电脑上。

## 安装

### 方式一：下载 exe（不用装 Python）

1. 下载并**解压整个文件夹**
2. 双击 `Etude.exe`
3. 打开后先去「设置」填大模型（选厂商 + 粘 API Key + 点「测试连接」）
4. 到「训练包」页输入 `appreciate`，回车

> 没有系统自带的 WebView2 时会自动改用浏览器打开界面，功能一样。

### 方式二：从源码跑

```bash
git clone https://github.com/whyao56/Etude.git
cd Etude/backend
python -m venv .venv && .venv/Scripts/activate
pip install -r requirements.txt
python run_etude.py
```

### 起不来怎么办

**第一站永远是自检**，它会直接告诉你缺什么：

```
Etude.exe --check
```

结果同时写在 `%LOCALAPPDATA%\Etude\logs\selfcheck.txt`。

## 已知限制（请务必读一下）

这一版**能用**，但请接受这三条：

1. **只在一台 Windows 机器上验证过。** 没测过：中文用户名下的路径、
   没有写权限的目录、杀毒软件拦截、公司代理环境、显示器缩放不是 100%。
2. **例句质量取决于你配的模型。** 程序不做质量校验。
   弱模型会偷懒给逐字翻译的「场景」，那样整套方法就退化成中译英了。
   **建议用指令遵循较强的模型。**
3. **真人长期使用效果未经验证。** 代码逻辑是照着理论写的，
   但「照着练三个月会怎样」没有任何数据支持，也不应该被声称。

其他：

- 只支持**英语**作为目标语言。
- 发音打分**没做** —— 评分是你自己打的（打字卡除外，那是逐字面比对）。
- 语速设置在「大模型 TTS」下**静默失效**（Edge TTS 下正常）。
- 没有 macOS / Linux 包，没有多设备同步。

完整的「没做什么、没验证什么」清单在
[docs/STATUS.md](https://github.com/whyao56/Etude/blob/main/docs/STATUS.md) ——
那份文档存在的意义是：如果三个月后发现效果不好，
应该能从中看出**是哪个假设错了**，而不是笼统地觉得「这个方法不行」。
