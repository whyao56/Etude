# Etude 0.1.0

**这一版是把整个项目重做了一遍，顺手多了一个能力：跟读评分。**

如果你只想知道该做什么：解压新包、双击 `Etude.exe`、进「训练」页练。
数据不用搬 —— 老库会自动加两张东西（`attempts` 表和 `cards.best_score` 列），
复习进度、训练包、配置全部沿用。

## 新的：跟读评分

口语卡上多了一个「跟读一句」。按下去开始录，说完按停，当场出分。

分数是四项加权，但四项**回答的是不同问题**，所以分开显示：

- **内容对不对** —— 词念全了吗。需要配一个 OpenAI 兼容的 `/audio/transcriptions`
  （whisper-1 之类）。没配就明确写「未检查」，**不参与总分**。
- **说完整了** —— 时长对不对（跟你自己的模型语音比）。
- **顺不顺** —— 停顿次数与最长停顿。
- **音量** —— 太小 / 爆音。

三个刻意的取舍：

1. **最高分不进 SRS 调度。** 跟读分只拿来给自己看。要是拿它排期，
   读不准音的人会永远卡在 10 分钟档。
2. **录音单独存 `recordings/`。** 「重新生成语音」清的是 `audio/`，
   不会顺手删掉你攒了两个月的录音。
3. **不配转写也能用。** 宁可少判一项并说清楚，也不拿空转写算个 0 分糊弄人。

## 新的：批量建包

训练包页 → 「批量」：

- **贴清单**：一行一个，或者用逗号/分号/顿号分隔，最多 40 个；
  已经建过的自动跳过，失败的下次重试。
- **让模型起草**：给个主题（比如「厨房里会用到的话」），
  模型给 12 条候选，勾完再生成。

## 新的：界面整套重做

- 四套配色：跟随系统 / 暖纸 / 冷白 / 深色。三档字号。
- 评分条粘在视口底部 —— 翻面后答案再长，四档评分也还在眼前。
- 真路由：`#/lessons/12`、`#/plans/3`。刷新还在原页，链接能贴给别人。
- 侧栏可以收成图标。提示条不再盖住按钮。

## 修掉的

- 设置页「配色 / 字号」小标签被压成小圆片（一个裸类名 `.pick` 误伤）。
- 卡片浏览页三个筛选项各占一整行。
- 「已有的训练包 / 5 个」折成两行。
- 提示条盖在评分键上导致「点了没反应」。

## 内部也换了

- 后端：`app/api.py` → `app/routes/*`（8 个），`app/db.py` → `app/store/*`（6 个）。
  拆包只搬代码不改语义，判据是**既有测试一个都不用改**。
- 前端：4520 行单文件 → 17 个原生 ES 模块 + 5 个 CSS 文件，仍然零构建。
- 新守卫 `scripts/check_frontend.py`：查导入名、图标名、类名、版本号。
  拆包时它有 118 个类名对不上 CSS —— 页面不报错，只是看起来「没做完」。
- 打包 38.6 MB / 149 文件（0.0.3 是 51.5 MB）。测试 316 个（0.0.3 是 273 个）。

## 升级注意

- 老数据目录直接能用，不用备份也不用搬。
- 如果你以前在设置里关过某个通道，这个开关还在。
- 0.0.x 时期的「简易 / 进阶」界面密度开关没有了 —— 高级项现在收在抽屉的
  「更多」里，不再需要整页切换。
- 跟读默认开启，录音默认保存。不想留录音：设置 → 发音训练 → 关掉「保存录音」。
