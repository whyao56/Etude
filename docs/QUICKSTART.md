# 快速开始

> README 讲「它是什么」，这份讲「**现在怎么让它跑起来**」。
> 目标是：从零到练上第一个训练包，不超过 10 分钟。

---

## 第 0 步：选一种跑法

| 你的情况 | 选哪个 | 要装什么 |
|---|---|---|
| 只是想用 | **A. 下载 exe** | 什么都不用装 |
| 想改代码 / 想看清楚它做了什么 | **B. 从源码跑** | Python 3.10+ |
| 想验证打包版是好的 | **C. 跑自检和端到端** | 同 B |

---

## A. 下载 exe

1. 打开 [Releases](https://github.com/whyao56/Etude/releases)，下 `Etude-0.0.1-win64.zip`
2. **解压整个文件夹**（别在压缩包里双击）
3. 双击 `Etude.exe`

### 如果双击没反应

**先去命令行跑一次自检**，它会直接告诉你缺什么：

```
Etude.exe --check
```

结果也会写在 `%LOCALAPPDATA%\Etude\logs\selfcheck.txt`。

> ⚠️ **不要只把 `Etude.exe` 单独拖出来。** 旁边的 `_internal` 文件夹是程序的一部分。
> 要挪位置就整个文件夹一起挪 —— 挪完数据不会丢（数据在 `%LOCALAPPDATA%`，和程序目录无关）。

### 关于那个黑框

`Etude.exe` 会带一个命令行窗口，**这是故意的**：它是
「双击没反应」的唯一出口。不想看可以最小化，别关 —— 关了程序也就退了。

---

## B. 从源码跑

```bash
git clone https://github.com/whyao56/Etude.git
cd Etude/backend

python -m venv .venv
.venv/Scripts/activate          # Windows
# source .venv/bin/activate     # macOS / Linux

pip install -r requirements.txt
python run_etude.py
```

启动后：

- 有原生窗口就直接开窗口（需要 WebView2，Win10 1803+ 通常自带）；
- 开不了就自动用系统默认浏览器打开，**功能一样**。

### 常用参数

```bash
python run_etude.py --no-window              # 只跑服务，自己开浏览器
python run_etude.py --port 9000              # 换端口
python run_etude.py --data-dir D:\etude-data # 换数据目录（不动真实数据）
python run_etude.py --check                  # 自检并退出
python run_etude.py --check-deep             # 自检 + 真连一次模型
python run_etude.py --version                # 只看版本号
```

### 不用真密钥就能试

第一次打开没有 API Key 也想先看看界面长什么样：

```bash
# 终端 1：起一个本地假模型
python ../scripts/openai_stub.py --port 18999

# 终端 2：起 Etude
python run_etude.py
```

然后在「设置」里：base_url 填 `http://127.0.0.1:18999/v1`，
密钥随便填，模型名填 `stub`。**全流程能跑通**，包括生成例句和合成语音
（假模型会返回一段合法的静音 mp3）。

假模型还能模拟各种坏情况 —— 模型名填 `fault-401` / `fault-403` /
`fault-404` / `fault-500` / `fault-429` / `fault-notjson` / `fault-fenced` /
`fault-messy` / `fault-slow` / `fault-nokey`，
用来验证错误提示有没有指向一个**能修好的方向**。
（比如 401 应该提示「检查密钥」，而不是「重试」—— 重试一百次也还是 401。）

## 第 1 步：配一个大模型

训练包的例句是模型生成的，**不配模型什么也做不了**。选一家就行：

| 厂商 | base_url | 模型名 | 备注 |
|---|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` | 便宜、指令遵循好，**推荐** |
| 通义千问（百炼） | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` | |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` | 有免费额度 |
| Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-32k` | |
| 豆包（火山方舟） | `https://ark.cn-beijing.volces.com/api/v3` | **接入点 ID**（`ep-xxxx`） | 模型名要填接入点 ID，不是 `doubao-xxx` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` | |
| 本地 Ollama | `http://localhost:11434/v1` | `qwen2.5:7b` | 密钥随便填 |

在「设置」里**选厂商 → 粘 API Key → 点「测试连接」**。
切厂商会自动把 base_url 和模型名一起换掉（只有厂商预置的这一套是配套的）。

### 密钥存在哪

`%LOCALAPPDATA%\Etude\config.json`，**仓库外**。
界面永远不会把它显示出来，`/api/config` 接口也不会回传。
设置页那个输入框写的是「已保存，留空表示不改动」—— 留空就是不改。

### 换个不那么常见的服务

选「自定义 / Custom」，base_url 填到 `/v1` 为止，模型名自己填。
只要对方提供 OpenAI 兼容的 `/chat/completions`，就能用。

> **建议用指令遵循较强的模型。** 生成器要求严格 JSON 输出，
> 而且对「场景不是翻译」这条约束很敏感 —— 弱模型会偷懒给逐字翻译，
> 那样整个方法就退化成中译英了。判断方法：生成一个包，
> 看口语卡的正面是不是「什么情况下会说这句话」而不是这句话的中文意思。

---

## 第 2 步：生成第一个训练包

到「训练包」页，输入一个词，回车。

建议第一次用 **`appreciate`** —— 它多义（感激 / 欣赏 / 理解 / 增值），
最能看出「不同上下文的例句」和「一个词一个意思」的区别。

生成过程：

```
1. 建包（立刻返回，界面出现一张卡显示「正在生成」）
2. 调模型要 8 条例句        ← 十几秒
3. 逐条合成语音（8 次）      ← 十几秒，可以并行
4. 铺开 40 张卡（8 例句 × 5 通道）
```

一共**大概 30~60 秒**。期间可以切到别的页面，回来自动续上进度
（每包独立轮询，同时生成几个也不会串）。

**语音挂掉不会让整个包废掉**：8 条里有 2 条没合成出来，
你会拿到「6 条能听、2 条标着缺语音」，训练包上会出现一个「补语音」按钮。

---

## 第 3 步：练

切到「训练」页。**键盘就行**：

```
空格 / Enter    翻面
1               没想起来
2               吃力
3               正常
4               秒答
```

### 五种卡各要注意什么

| 通道 | 你要做的 | **不要**做的 |
|---|---|---|
| 阅读 | 看英文，让场景自己浮出来 | 不要读出声，不要想中文 |
| 听力 | 只听，直接进入场景 | 不要先去看原文，不要在脑子里过一遍中文 |
| 口语 | **真的出声说出来** | 不要只在心里默念 —— 那是四种能力里的另一种 |
| 打字 | 看场景打出英文 | —— 打完会逐词标出差异（红=漏/错，黄=多打） |
| 造句 | 换掉主/谓/宾造新句 | 不要照抄原句只换一个词 |

评分**只影响下次什么时候出现**，不影响对错（打字卡除外，那个是逐字面比对）。

评「没想起来」会让这张卡 **10 分钟后再出现一次**，而不是推到明天 ——
当次会话里就该再遇到它。

---

## 第 4 步：每天 5 分钟

「训练」页打开就是当天的队列：**到期的卡 + 新卡配额**（默认每天 5 张新卡）。
练完会显示「今天练完了」。

想调容量去「设置 → 学习」：

| 设置项 | 默认 | 说明 |
|---|---|---|
| 每天新卡数量 | 5 | 太大容易积压 |
| 每包例句数 | 8 | 多则上下文更丰富，也更贵 |
| 每句中文说法数 | 3 | 同一句话要有几种彼此不同的中文 |
| 中文说法策略 | 轮换 | 「轮换」= 每次随机取一种；「固定」= 始终第一种 |

## 排错决策树

**第一站永远是**：

```
Etude.exe --check
```

它会逐项报：数据目录能不能写 / 界面文件在不在 / 数据库能不能查 /
模型配没配 / 语音引擎在不在 / 窗口组件有没有 / 音频缓存 / 运行形态。
每项分三档：`ok` / `warn` / `fail`。**看到 `warn` 不等于坏** ——
比如缺 WebView2 只是「用不了原生窗口」，会退回浏览器，功能一样。

### 按现象找

| 现象 | 大概率是什么 | 怎么做 |
|---|---|---|
| 双击完全没反应 | 缺运行时 / 只把 exe 拖出来了 | 命令行跑 `--check` |
| 黑框闪一下就没了 | 同上 | 在**命令行里**运行 exe（不是双击），就能看到报错 |
| 界面打开了，生成报错 | 密钥错（401）/ 模型名错（404）/ 额度用光（429） | 报错里写着下一步做什么，照着做 |
| 「测试连接」通了，生成还是失败 | 测试只发一句话，生成要求严格 JSON，弱模型会栽在这 | 换个模型试 |
| 有例句但没声音 | Edge TTS 短暂不可用 / 网络问题 | 训练包里点「补语音」；也可以先换个音色再试 |
| 版本号显示得不对 | **端口上留着一个旧进程** | 关掉所有 `Etude.exe` 再开。`/api/health` 会回报 pid，一看就知道 |
| 生成很慢 / 超时 | 8 条例句本来就要几十秒 | 设置里调大超时，或换个更快的模型 |
| 练了几天就不出卡了 | 队列没到期 | 正常。间隔重复本来就是「越熟越少」 |
| 数据看着丢了 | 换了数据目录 / 起在了另一个实例上 | 看「设置」页最上面显示的数据目录路径 |

### 想从零开始

数据全在 `%LOCALAPPDATA%\Etude`。整个删掉就是全新状态。
**删之前先去「设置 → 备份数据库」存一份**（它用的是 SQLite 自己的
`VACUUM INTO`，导出的是一份自洽的单文件 —— 直接复制主文件会丢掉
还没落盘的那部分，打开是好的、内容却是旧的）。

## C. 验证打包版（改代码的人看这里）

```bash
cd backend

# 1. 全部测试
python -m pytest tests/ -q

# 2. 前端守卫（调用点 + 事件名大小写）
python ../scripts/check_js.py

# 3. 打包（含归档核对 + 冻结态自检）
python ../scripts/build_exe.py

# 4. 起假模型，对着打包版跑端到端
python ../scripts/openai_stub.py --port 18999 &
python ../scripts/e2e_check.py --llm-base http://127.0.0.1:18999/v1

# 5. 真浏览器里点一遍（需要本机有 Chrome）
node ../scripts/ui_smoke.js

# 6. 发版前先算校验和
python ../scripts/make_release.py --check
```

`3` 不会覆盖上一份产物 —— `dist/Etude` 已存在就写到 `dist/build2/Etude`，
再下次 `build3`。`4` 和 `6` 会自动用**最近一次**的那份（`scripts/products.py`）。
想清理自己删 `dist/` 下的旧目录。

`4` 是**关键的一步**：源码态跑通不等于打包后跑通。
它会用一个临时数据目录（不碰你的真实数据）对打包版打真实 HTTP，
断言写成 `N/N` 输出。

`6` 的 `--check` 只打包、打印 SHA256、**不上传**。
真发版去掉 `--check`，但它会拦住你 ——
如果 `docs/releases/v0.0.1.md` 里没印这个包的 SHA256，
脚本会拒绝发布（发行说明和产物对不上，就是「文档说谎」的经典症状）。
