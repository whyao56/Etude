> 记法：每一轮记四件事 —— **起点**（这一轮开始时手上有什么）、
> **怎么做**、**踩到什么**（只记真的花过时间的）、**怎么验证的**。
>
> 踩坑那部分是这份日志唯一有长期价值的部分：源码读一遍就知道的东西不用记，

## 第 0 轮 · 读材料，定产品形态

**起点**：一张需求单 ——「做一个学习自然语言的工具，接入大模型，做成 exe 发到 GitHub，
版号 0.0.1，先做英语」。

**读了三份 docx + 一份讲稿 + 两篇知乎**，记下六条主张（后来成了 THEORY.md 的骨架）。

**这一轮真正的产出是一个决定**：GitHub 上做「AI 生成语言卡片」的项目已经很多
（mnemorai / han-flash / anki_ai / anki-cards-ai-generator …），
绝大多数是**单词 → 卡片**的造卡器。

要做出区别，只有一条路：**不做造卡器，做训练循环**。
所以产品形态定成「给一个词 → 8 条例句 × 5 种练法 → 自带间隔重复」。

**名字**：Etude（/eɪˈtjuːd/），音乐里的「练习曲」——专为练技巧而写，
不讲故事、不为演出，纯粹为了让手指形成本能。

**四个要用户拍板的问题，得到的答复**：

| 问题 | 答复 | 落成什么 |
|---|---|---|
| 复习方式 | 「先不用管 anki，那是以后要做的」 | 做**内置**训练器，不做 `.apkg` 导出 |
| 大模型接入 | 「两者结合」 | 7 家预置厂商 + 自定义 base_url |
| 语音合成 | 「两者都支持」 | Edge TTS（免费）+ OpenAI 兼容 TTS |
| 项目名 | 「你自己给我取一个」 | Etude |

## 第 1 轮 · 骨架：paths / config / db / srs

**起点**：空目录。

**怎么做**：先定**最容易返工**的四层 —— 这三个都是「等打包了才发现要改、
就得动整条链路」的东西。

- `paths.py`：全项目唯一判断「在不在 exe 里」的地方。三条规则 ——
  可写的进用户目录、只读的进包内资源、**判断只在这一处做**。
- `config.py`：配置存 `%LOCALAPPDATA%\Etude\config.json`，**在仓库外**。
  这不是洁癖，是从根上杜绝「把 API Key 提交上去」这种事故。
- `db.py`：四张表。定主键 `(例句, 通道)`。
- `srs.py`：纯函数，不碰数据库、不碰时间。

**踩到的**：

1. **端口**。上一个项目用的是 8787，那台机器上到现在还留着一堆旧进程，
   手工 `curl` 会打到旧进程上、看到错的版本和错的数据目录。
   这个项目换成 `8977`。**换个不重复的端口比学会「先查再打」便宜。**
2. **BLAS 线程限流必须放在 `app/__init__.py` 最上面**，
   在任何子模块 import 之前。放到 `db.py` 里就晚了 ——
   numpy 一旦被 import 过，这些环境变量就不再生效。
   这个项目理论上用不到 numpy，但 venv 里装着（上个项目的遗留），
   所以入口处先设好 `OPENBLAS_NUM_THREADS=1` 之类，防的是「某次不小心
   import 进来，起 32 个线程抢一个 CPU」。

**怎么验证的**：`test_core.py`。其中一条值得单说 ——
`test_frozen_check_happens_in_exactly_one_place` **全仓搜索 `sys.frozen`**，
断言只有 `paths.py` 里出现。这条测试保护的是「规则一多就会漏」的风险。

## 第 2 轮 · 提示词与两个 provider

**起点**：能存数据了，但没内容。

**怎么做**：

- `prompts.py` 的 `SYSTEM` 里把「**场景是情境，不是翻译**」写成加粗级的强调。
  这是整个项目最容易做错的一处 —— 场景写成逐字翻译，口语卡就退化成中译英，
  整个方法废掉。
- `llm.py`：8 家预置 + OpenAI 兼容协议统一接入。重点是 `explain_error()`。
- `tts.py`：双引擎，内容寻址文件名。

**踩到的**：

3. **`extract_json()` 面对「解说词里有花括号」会放弃**。
   原实现是「找第一个 `{`，配平扫描，失败就返回 None」。
   模型很常见的输出是「好的，这是你要的 JSON： {…} 希望能帮到你 }」——
   直接栽。改成**遍历每一个 `{`** 逐个尝试。

4. **假装 json_mode 一定成功**。有的服务不认 `response_format`，
   回 400。原来的处理是「去掉 `response_format` 重试一次」——
   但这会被算进重试次数，于是「格式不兼容」和「服务不稳定」共用一个预算。
   改成：400 + json_mode 的这次重试**不计入重试次数**。

5. **`explain_error()` 的顺序**。这条来自上一个项目最贵的一类 bug：
   如果「缺组件」判断排在网络关键词之后，用户会收到
   「**重试 / 换个网络 / 换个镜像**」—— 这条建议永远修不好问题，
   因为真正的原因是 `ModuleNotFoundError`。
   现在的顺序是：① `ImportError`/`ModuleNotFoundError` → ② 本机地址连不上
   → ③ HTTP 状态码分类 → ④ 超时/网络 → ⑤ 未知。
   有测试盯着这条，而且断言里写清了「为什么」：
   `assert "重试也不会好" in hint`，因为它确实说了正确的话。

6. **`_synthesize_*` 成功返回但不写字节**。有的音频库会「成功返回」一个
   它其实没写成功的文件。现在合成完**检查文件真的存在且非空**，
   不然会在几十分钟后表现为「有例句但没声音」，而那时已经很难定位了。

7. **音频路径存相对路径**。绝对路径换个数据目录就是死链，
   备份还原到另一台机器全废。

**怎么验证的**：`test_e2e_stub.py` 起真 HTTP 假模型，逐个 fault 断言
「每种故障给出的提示**互不相同**」（只断言「有提示」是不够的，
三种故障给同一句话等于没提示）。另有一条专门断言「三种故障说的话不一样」。

## 第 3 轮 · 流水线、接口、自检、窗口

**起点**：零件齐了，没有装配线。

**怎么做**：

- `pipeline.py`：作业表在内存，`_JOBS`；`recover_stale()` 把上次崩在
  `generating` 的行标成 `failed`。
- `api.py`：`/api/lessons` 立刻返回，生成走后台线程池。
- `server.py`：端口占用的分类处理。
- `selfcheck.py`：八项。
- `desktop.py`：开不了窗口就返回 `False`。

**踩到的**：

8. **`ready` 和 `complete` 合成一个布尔值**。
   第一版 `readiness()` 返回单个布尔值，算的是「例句齐、音频也齐」。
   后果：Edge TTS 抽风 → 整个包判定不可练 → 读写造句四个通道明明好的，
   跟着一起被封掉。
   拆成两个字段，各自对应一种界面行为。

9. **`server.join()` 从窗口关闭回调里调会死锁**。
   表现是「关了窗口，进程还在任务管理器里」。
   改成 `ask_stop()` 只置标志，join 留给主线程（带 5 秒超时）。

10. **无脑换端口会造出两个实例**。
    用户双击两次 exe 是最常见的情况。无脑换端口 → 第二个实例悄悄起在
    随机端口上、开新窗口、两个窗口互相盖同一个 sqlite，
    表现是「数据丢了」。
    改成先 `probe_etude()`：对面应答且是自己 → **复用**。

11. **`/api/health` 要自述**。返回 pid、版本、运行形态、数据目录。
    这条接口的全部意义就是「让旧进程一眼可辨」。

12. **界面 HTML 必须 `no-store`**。
    打包后界面从 `_internal/` 读，浏览器拿旧 HTML 会表现成
    「代码改了但没生效」。宁可每次重读磁盘。

13. **`sys.modules.setdefault("app.desktop", ...)`**。
    PyInstaller 下 `run_etude.py` 里 `import app.desktop` 和
    `app/desktop.py` 内部 `from app import desktop` 有可能变成**两个模块对象**，
    于是「关闭标志」一个模块设了、另一个模块读不到。
    这行 setdefault 防的就是模块分裂。

**怎么验证的**：`test_api.py`。值得单说的两条 ——
「自检在缺窗口时**不能报 fail**」（报 fail 会把一个「能用但没那么好看」
的状态说成「不能用」，那是误导），
以及「音频路径穿越」（`..%2F..%2Fconfig.json` 要在进文件系统前被挡掉）。

## 第 4 轮 · 前端

**起点**：接口齐了，没界面。

**怎么做**：一个 HTML 文件，约 1480 行，零构建、零 CDN、不用框架。

- 不用 CDN：**断网也要能练**。例句和语音都在本机，
  没道理打开界面还要等一个 jsdelivr 请求。
- 不用框架：没有编译步骤 = 双击就能调界面。代价是失去编译期检查 ——
  用 `check_js.py` 补。
- 不用 `innerHTML` 拼字符串：例句里有用户输入的目标词，拼字符串就是 XSS 入口。
  全部走 `el(tag, attrs, children)` 建 DOM。

**踩到的**：

14. **最严重的一个 bug：所有按钮点击都是死的。**
    `el()` 里写的是 `key.slice(2)`，于是 `onClick` →
    `addEventListener("Click", ...)`。
    **事件类型串是大小写敏感的**，一个都不会触发。

    这个 bug 的可怕之处在于它**完全隐身**：
    界面照常画出来；截图看不出来（元素都在）；Python 测试测不到
    （它不跑 JS）；控制台**没有报错**（`addEventListener` 接受任意字符串）。
    只有真在浏览器里点一下才会发现。

    旁证很有意思：这个 bug 存在期间，`screenshots.js` 只能生成 **8 张**
    截图（`04-listen-front.png` 一直缺失 —— 那一步要先点一个按钮才能到）。
    修好之后 9 张齐全。

    修法是 `.toLowerCase()`，然后补了两条守卫：
    `check_js.py` 里的 `bad_event_type_literals()`（查字面量），
    以及 `test_guards.py` 里的反证用例（故意喂一个 `onClick` 进去，
    断言守卫会报）。

15. **`pollLesson` 用单个共享定时器**。同时生成多个包时，
    只有最后一个被轮询，前面那些永远停在「正在生成」。
    改成 `pollTimers = new Map()`，键是 lesson_id。

16. **`retryLesson` 会创建一个名叫 `__retry__` 的训练包**（写的时候
    图省事，让重生成走同一条建包路径）。删掉，改成
    `POST /api/lessons/{id}/regenerate`。

17. **`practiceOne` 靠推算卡片 id**。`card_id = 例句序号 * 5 + 通道序号`
    ——依赖「卡片 id 连续」这个前提，重生成一次就没了。
    改成 `lesson_detail()` 返回 `cards` 清单，前端**查表**。

18. **同一张卡内部中文说法要稳定**。第一版是每次翻面都重新随机取一种，
    读起来像界面在抖。改成 `state.variantIndex` 在 `fetchCard()` 时定下来。

19. **`loadStats` 未定义**（守卫抓到的）。删掉那两处调用。

**怎么验证的**：`check_js.py`（73 处调用全部有定义 + 事件名大小写）、
`ui_smoke.js`（真浏览器点一遍，21/21 通过，同时收集控制台错误）。

## 第 5 轮 · 守卫被自己骗了（这一轮最值钱）

**起点**：`check_js.py` 第一次跑，报了 **8 个「函数未定义」**。

**看起来**：8 个我明明写了的函数被报未定义。

**真相**：探针坏了，伪装成被测对象坏了。

`diffWords` 里有个正则字面量 `/[^a-z0-9' ]/g`，里面那个单引号被朴素的
清洗器当成字符串开头，于是它从那里开始吃，一直吃到下一个单引号 ——
**中间一大段代码整个被当成字符串吃掉了**，里面定义的函数自然「不存在」。

**修法**：

1. 加 `_regex_allowed_before(text, index)`，判断一个 `/` 到底是正则开头
   还是除法运算符（看前一个非空白字符：是标识符/数字/`)`/`]` 就是除法，
   否则是正则）。顺便处理了正则自己的字符类 `[...]` 里的 `/`。
2. 加 `_SELF_TEST_SAMPLES`（5 个样本，覆盖「正则里带引号」「除法」
   「注释」「字符串」「模板串」）+ `self_test()`。
   **每次运行在给结论之前先验探针本身。**

**验证**：把 `function reveal()` 改名成 `revealTheCard()`，
守卫报 `index.html:1366 reveal()`、退出码 1。**探针能失败才算探针。**

**这一轮的教训值得单独记**：
> 探针坏了会伪装成被测对象坏了。
> 而它给出的错误方向（「你有 8 个函数没定义」）会让你去改**完全正确**的代码。

## 第 7 轮 · 打包

**起点**：源码态全绿。

**怎么做**：onedir（不是 onefile），`console=True`，显式 `excludes`。

**踩到的**：

27. **onedir vs onefile**。onefile 每次启动解压到临时目录、
    **退出即删** —— 用户会以为数据丢了。
28. **`excludes` 不是可选的**。开发 venv 里装着上个项目的
    faster-whisper / onnxruntime / tokenizers / av / soundcard，
    PyInstaller 会顺着 import 图全拉进来。显式切断后 **49.0 MB / 125 个文件**。
29. **归档核对不能用 `grep` 二进制**。拿 `grep` 去 exe 里找模块名，
    假阳性一堆（字符串池里有大量偶然命中）。
    改用 PyInstaller 自己的归档读取器，查 10 个必需模块。
    少一个就**不产出 dist**。
30. **体积报警只报不失败**。超 260 MB 打印警告。失败会把合理的增长
    （加了功能）也拦下来。
31. **`--check` 必须在控制台跑**。所以 `console=True` 不能关 ——
    它是「双击没反应」的唯一出口。

**怎么验证的**：`build_exe.py` 六步 —— 前置守卫 → 版本一致 → 打包
→ 归档核对 10/10 → 体积 → **冻结态跑 `--check`**。
然后 `e2e_check.py` 对打包版打真实 HTTP：**18/18 通过**。
用临时数据目录（`ETUDE_DATA_DIR` 指到系统临时目录），完全不碰真实数据。

## 第 8 轮 · 截图、文档、以及一个被安全策略挡下来的验证

**起点**：功能齐了，要出文档。

**怎么做**：`screenshots.js` 用自写的 CDP 客户端（`cdp.js`）驱动本机 Chrome，
生成 README 的 9 张截图。

**踩到的**：

32. **截图被系统显示缩放压小**。设了 `SHOT_WIDTH=1400`，
    PNG 实测 1080 宽。Chrome 要加 `--force-device-scale-factor=1`
    —— 不设的话，任何有显示缩放的机器上图都会糊。
33. **截图必须脚本化，不能手截**。理由很直白：
    **旧图比没有图更糟。** 手工截的图在下一版就会开始说谎，
    而脚本化的图跑一次就能跟上。
34. **PowerShell 启动 GUI 程序被安全策略拒绝**。
    我本来想「起一个窗口，确认它开得起来」。
    报错是「Invoking PowerShell from Bash bypasses PowerShell security checks」。

    **没有强行绕过。** 改成把「原生窗口可用性」做成 `selfcheck.py` 里的
    八项之一（`_window_status()`），缺 WebView2 只报 `warn` ——
    因为会退回浏览器、功能一样。**这是更有价值的做法**：
    它变成用户能自己跑、能自己看见的一项检查，
    而不是我在这里替所有机器验证一次。

**怎么验证的**：9 张截图齐全（1400×940，深色主题）、
`ui_smoke.js` 21/21、113 项测试通过。

## 这一版没做的事

留着防止下次有人以为「忘了」：

- **Anki 导出**（`.apkg`）—— 用户明确说「先不用管 anki，那是以后要做的」。
- **发音打分 / 语音识别**—— 需要参考音素序列和打分模型（几百 MB），
  0.0.1 的目标是先把卡片循环跑通。**这是范围决定，不是否定它的价值。**
- **英语以外的语言** —— 用户说「先用英语为开头」。
  架构上只差提示词分支和音色表（见 THEORY.md 第四节）。
- **macOS / Linux 桌面包** —— 只在 Windows 上打包和验证过。
- **真人长期使用效果** —— 代码逻辑对着理论写了，
  但「照着练三个月会怎样」没有任何数据支持，也不应该被声称。
